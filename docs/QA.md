## 정적 UI 검토

- 하루 시리즈 공통 색상·타이포그래피와 원본 아이콘 사용
- 플레이 / 내 기록 / 게임 방법, 설정 시트 연결
- 게임 중 난이도 변경·새 게임 확인, 기록 삭제 확인
- 앱이나 플레이 화면을 벗어나면 시간 정지 및 보드 숨김
- 실제 창 크기에 맞춘 보드 높이, 칸 확대·축소 및 상하좌우 스크롤
- 공개된 칸 상태만 접근성 설명에 포함, 열린 칸에는 주변 열기를 제공하고 깃발 동작은 닫힌 칸에만 제공
- 기록은 기기의 벽시계 정렬 대신 실제 완료 순서를 유지
- 앱은 사용자 승인 팝업이 필요한 Android 권한을 사용하지 않음. AndroidX가 추가하는 앱 내부 동적 수신자용 signature 권한만 포함

## 실제 기기 확인 범위

검증 환경의 `adb devices -l`에 연결된 기기가 없었습니다. **실제 휴대폰 설치, 화면 렌더링, 터치·진동 및 백그라운드 왕복은 아직 확인하지 못했습니다.** 아래 항목은 기기 QA용 목록이며 통과했다고 주장하는 항목이 아닙니다.

- [ ] 최초 설치 후 앱 이름·아이콘, 밝은/어두운 화면 확인
- [ ] 상·중·하에서 첫 칸, 길게 누르기, 깃발 모드, 숫자 주변 열기
- [ ] 작은 화면·가로 화면·큰 글자에서 확대와 스크롤
- [ ] 일시정지, 홈 버튼, 앱 전환, 화면 회전 후 이어하기와 시간
- [ ] 승리·패배, 최고 기록, 연승, 공유 대상 선택 창
- [ ] 앱 재실행 후 보드·시간·설정·기록 복원
- [ ] 기록 초기화 후 재실행해도 삭제 기록이 다시 나타나지 않음
- [ ] 같은 서명키로 만든 후속 버전 덮어 설치 시 기존 기록 유지

## 배포 특성

현재 산출물은 **자체 서명된 디버그 APK**이며 Google Play 등록본이 아닙니다. 서명키는 `.android/debug.keystore`에 보관하고 Git·소스 ZIP·GitHub 릴리스에서 제외합니다. CI가 만드는 키는 검증 전용이며 사용자 업데이트 빌드에 사용하지 않습니다.

Lint의 `UseKtx` 제안은 저장 성공 여부를 확인하려고 `SharedPreferences.Editor.commit()`의 Boolean 반환값을 직접 사용한 부분입니다. `ObsoleteSdkInt` 제안은 minSdk 26과 같은 적응형 아이콘 리소스 폴더의 버전 표기가 중복된 부분입니다. 둘 다 검사 오류가 아닙니다.

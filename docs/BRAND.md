# 하루지뢰찾기 · 하루 시리즈 디자인

## 이름과 문장

- 앱 이름: **하루지뢰찾기**
- 영문 프로젝트 이름: HaruMinesweeper
- 기본 문장: **한 칸씩, 기분 좋은 하루.**
- 하루닿음(Semantle), 하루일본어(Japanese Conversation)와 같은 시리즈의 독립 앱이다.
- 사용자에게 부담을 주지 않는 짧고 다정한 문장을 쓴다. 실패는 다시 도전할 수 있는 일로 표현한다.

## 구성과 재사용

- 여백이 넉넉한 앱 헤더, 둥근 흰색 카드, 얇은 경계선, 선명한 숫자를 사용한다.
- 카드 모서리는 약 22–24dp, 버튼과 작은 요소는 12–18dp로 통일한다.
- 본문 기본 크기는 14–16sp, 제목은 24–28sp이다. 시스템 글자 크기 설정을 존중한다.
- 공통 테마는 `app/src/main/java/com/harudaeum/minesweeper/ui/theme/Theme.kt`에 모은다.
- 새 시리즈 앱에서는 동일한 간격·서체·색상 역할을 유지하고 이름, 아이콘, 주요 활동만 변경한다.

## 아이콘

`brand/haru-minesweeper.svg`는 이 프로젝트를 위해 직접 구성한 원본 벡터다. 코랄 사각형 안의 세 타일은 지뢰찾기 보드를, 깃발과 숫자는 게임 조작을, 노란 하트는 다정한 선물의 느낌을 표현한다. Android용 벡터와 적응형 아이콘도 같은 도형을 사용한다. 다른 앱의 로고나 외부 이미지 파일을 복제하지 않는다.

Android 런처는 적응형·단색 아이콘을 제공하고 앱 내부에는 `@drawable/ic_haru_mark`를 사용한다.
